# 宿舍生活分摊工具（G18 组）

> 软件工程课程小组项目 · 面向在校大学生的**宿舍公共费用与事务管理工具**
> 以寝室为单位，覆盖电费、水费等公共费用的记账、分析与分摊，辅以卫生值日排班，让宿舍生活更简单、更公平。

## 项目简介

宿舍琐事虽小，却是消耗室友关系的主要来源。本项目针对两大痛点设计：

- **费用分摊混乱**：水电费、公共日用品等开支依赖口头约定，缺少统一记录，月底算不清、分不公。
- **卫生分配不均**：值日任务无排班、无打卡、无记录，执行全凭自觉。

核心理念：**先记账、再分析、后分摊** —— 日常公共费用完整记录是公平分摊的前提；分摊支持均摊、按比例、指定人员等多种方式（如某成员电脑耗电量大可承担更高比例）。

- 载体形式：微信小程序（以寝室为单位，用户即寝室成员）
- 项目性质：非商用软件工程课程作业，预计直接开发成本接近零

## 需求要点（来自 10/21 导师指导）

调研与设计已在原始"电费 AA 工具"基础上重新定位为**宿舍公共费用管理工具**，关键结论：

1. **定位修正**：不是单纯分摊计算器，而是"公共费用记录 + 分析 + 分配方案"的完整闭环；电费、水费属于刨不掉的固定类别，应**预制在模板中**而非空白模板，允许用户在此基础上追加。
2. **费用类型覆盖要全**：需调研不同寝室（含文科/理科、男生/女生宿舍）的差异性费用，避免评审时被指出遗漏。
3. **权限模型**：以寝室为单位，需区分成员录入权限、修改权限；默认宿舍长持有管理员权限，同时支持指定不同人分管不同费用条目（如 A 记电费、B 记水费）。
4. **分摊规则要细致**：支持非均摊比例（如高功耗设备使用者承担 30%、其余三人分摊剩余；高频洗澡成员在水费上单独加权），减少公平性摩擦。
5. **AI 能力分级看待**：基础统计分析（横向对比男女寝平均电费、纵向逐月趋势、人均分摊报告）**不依赖 AI**，普通统计即可实现；AI 生成月度/周度费用报告属于**后期可选增强**，须先验证真实用户需求再决定是否纳入，避免范围蔓延。
6. **反馈机制**：需提供用户向管理员反馈功能需求的通道，当前未实现，但应在预期功能列表中**明确列出**。
7. **平台合规**：正式发布小程序需企业/组织主体认证（个人主体受限），流程最繁琐的是身份审批；课程演示可用**测试账号 + 指定体验成员**方案。除 AI 调用外大部分开发环节免费。
8. **工作量提醒**：导师明确指出当前功能偏简、工作量偏少，要求**先做全做精基础数据管理**，并加强对真实用户的调研。

## 风险与应对

| 风险 | 等级 | 应对措施 |
| --- | --- | --- |
| 功能范围蔓延 | 中 | 严格限定 MVP，AI 报告等非核心项延后 |
| 提醒推送受限 | 中 | 降级为站内提醒或邮件 |
| 多用户测试困难 | 中 | 多账号模拟 + 邀请室友实际试用 |
| 结算算法出错 | 低 | 单元测试覆盖整数分换算与分摊合计 |
| 小程序主体认证 | 中 | 采用测试账号 + 指定体验者 |
